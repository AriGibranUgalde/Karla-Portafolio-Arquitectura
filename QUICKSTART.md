# Guía rápida

## Primera vez

```bash
pnpm install
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Cada vez que quieras trabajar

```bash
pnpm dev
```

## Antes de guardar cambios importantes

```bash
pnpm check
```

## Ver la versión de producción localmente

```bash
pnpm build
pnpm start
```

## Detener el servidor

En la terminal donde se está ejecutando, presiona:

```text
Ctrl + C
```

## Requisitos

```bash
node --version
pnpm --version
```

Se requiere Node.js 24 o superior y pnpm 11.19.0 o superior.
