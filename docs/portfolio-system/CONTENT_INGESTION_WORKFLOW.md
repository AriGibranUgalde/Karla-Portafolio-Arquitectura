# Content Ingestion Workflow

## Source
Content will be provided progressively through Google Drive or equivalent folders.

Drive is primarily a:

**Content Source and Delivery Method**

It is not automatically the production storage provider.

## Possible Content
- Project folders.
- Photographs.
- Renders.
- Plans.
- Diagrams.
- PDFs.
- CV.
- Documents.
- Texts.
- Reference material.
- Original high-resolution images.

## Ingestion Process
1. Analyze folder structure.
2. Analyze files.
3. Identify project relationships.
4. Identify portfolio section.
5. Detect duplicates.
6. Detect reference-only material.
7. Determine publishable content.
8. Identify optimization needs.
9. Organize content.
10. Prepare it for the project content structure.

Do not publish everything automatically.

## Classification
### Profile
- Professional photo.
- Biography.
- Contact information.

### CV
- CV PDF.
- Structured curriculum data.

### Projects
- Photographs.
- Renders.
- Plans.
- Diagrams.
- Descriptions.
- Project reports.
- PDFs.
- Technical material.

### Documents
- Portfolio PDF.
- Certificates.
- Public professional documents.

### Reference
Material used only to understand or prepare a project.
