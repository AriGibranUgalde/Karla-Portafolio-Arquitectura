# Content Structure Specification

## Purpose
Define how portfolio content is organized without a CMS.

## Main Sections
- Home.
- About / Profile.
- Projects.
- CV.
- Experience.
- Education.
- Skills.
- Software.
- Documents.
- Contact.

## Projects
Each project may contain:
- Name.
- Slug.
- Category.
- Type.
- Location.
- Year.
- Status.
- Area.
- Role / participation.
- Short description.
- Full description.
- Concept.
- Design strategy.
- Materials.
- Software used.
- Cover image.
- Gallery.
- Renders.
- Photographs.
- Plans.
- Diagrams.
- PDFs.
- Documents.
- Display order.
- Featured flag.

Not every project needs every field.

## Content Format
Prefer one clear system:
- Markdown / MDX.
- JSON.
- YAML.
- TypeScript objects.
- Framework-native content collections.
