# Public Portfolio Experience

## Visual Direction
The public site should feel:
- Minimal.
- Architectural.
- Editorial.
- Elegant.
- Contemporary.
- Clean.
- Professional.
- Visual.
- Spacious.

Architecture imagery should be the main protagonist.

## Avoid
- Generic template appearance.
- Excessive card layouts.
- Decorative gradients without purpose.
- Excessive animation.
- Dashboard-like layouts.
- Generic AI-looking design.

## Responsive Design
Support:
- Desktop.
- Laptop.
- Tablet.
- Smartphone.

Mobile should not simply be a compressed desktop layout.

## Performance
Prioritize:
- AVIF.
- WebP.
- Responsive images.
- `srcset`.
- Lazy loading.
- Caching.
- Compression.
- Code splitting.
- JavaScript optimization.
- CSS optimization.
- Font optimization.

Monitor:
- LCP.
- CLS.
- INP.
- Core Web Vitals.

## SEO
Prepare:
- Page titles.
- Meta descriptions.
- Open Graph.
- Sitemap.
- Robots.txt.
- Clean URLs.
- Project slugs.
- Schema when appropriate.
- Image metadata.
- Indexable content.

Each project should have its own URL.

## Accessibility
Consider:
- Contrast.
- Keyboard navigation.
- Alt text.
- Heading hierarchy.
- Accessible links and forms.
- Focus states.
- Semantic HTML.
- Readable typography.
